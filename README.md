# Зоопарк – система за управление на животни

Конзолна програма на C#, която управлява животните в зоопарк. В зоопарка има лъв, слон, папагал, делфин и пингвин. Чрез менюто може да се види информация за всяко животно, какъв звук издава и с какво се храни, кои животни плуват, летят или бягат, кое е най-тежкото животно и каква е средната възраст. Има и търсене на животно по име.

В проекта се използват:

- абстрактният клас `Animal` с абстрактния метод `MakeSound()` и виртуалния метод `Eat()`
- наследяване – всички животни наследяват `Animal` и извикват неговия конструктор с `base`
- полиморфизъм – всички животни са в един `List<Animal>` и всяко изпълнява своята версия на методите
- интерфейсите `ISwimmable`, `IFlyable` и `IRunnable`, проверявани с оператора `is`

## Стартиране

В папката на проекта:

```
dotnet run
```
